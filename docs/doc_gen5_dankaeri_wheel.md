# 第5世代：段返り水車式歩行機（クランク・水移動一体化）

**対応ファイル**: `gen5_walker.blend`（Gen-4モデルからの改造）/ `walker_gen5.py`
（PyBulletシミュレータ）/ `gen5_gait_strip.png`（初歩行の時系列）/
`gen5_walker_walk.mp4`（保守型歩行の動画）。

---

## 1. 概要

Gen-4は「水は足元に固定し、駆動連鎖（ポンプ→ベローズ→ラック→ピニオン→
クランク）で反転を作る」構成だった。Gen-5は**水タンクをクランク腕の先端に
搭載し、中空腕を導管化**することで、駆動連鎖を丸ごと消滅させた。よりオリジナル
の段返り童子——体内の水銀が移動して体ごと返る——に忠実な系である。

クランク関節は完全受動（トルク制御なし）。唯一の作動は**ハブのポンプ・弁に
よるタンク間の水移送**であり、質量配置の変化だけが機体を歩かせる。

## 2. 機体構成（Gen-4からの差分）

| 要素 | 仕様 |
|---|---|
| クランク | 腕−45°傾斜・長さ0.32m。タンク取付は首部経由で軸線からオフセット |
| タンク | 2基、軸から(±0.355, ∓0.44, ±0.290)＝レバー半径0.459m。質量線はピン線の39°先行（C2同回転向き） |
| ポンプ・弁 | クランクハブ中央（回転側搭載：偏心ゼロ・油圧対称・回転シール不要） |
| 股関節 | 連続回転ゴンドラ軸受＋一方向コード（紐）＋フリーホイール（後方巻き戻し禁止） |
| 足 | 半かまぼこロッカー：踵平底＋**つま先弧R=0.40**（Gen-4の0.30から拡大）、脚軸より0.04前方оффセット、ゴム底（μ≈2.0） |
| 足バネ | K=1500 N/m（単脚支持31Nで底付き回避のため増強） |
| 撤去部品 | 足水嚢・足ポンプ・ラック・ピニオン・ベローズ・外部ホース・デテント爪 |
| 総質量 | 3.15kg（うち水1.2kg） |

## 3. 動作原理 — 段返り童子との対応

1. **構え（かまえ）**: タンクL満水時、クランクが約−30°に静定し、満水タンクは
   軸の15cm後方にぶら下がる。このとき**右足がピンごと前方斜め位置に浮上**
   （すりあし回避のクリアランス）。浮いた脚の重量が吊り平衡を手前で止める
   釣り合いが、次の一歩の方向も確定する。
2. **揚水**: ポンプが後方低タンクから前方高タンクへ移送（1歩あたりの主エネル
   ギー入力）。弁は高速回転中は凍結（人形の「反転中は水銀が動かない」）。
3. **反転**: 質量交差後、満水タンクが**低所で支点脇をすり抜ける振り子通過型**
   の半回転。人形の「重い頭は支点際・軽い側が返る」に対応。
4. **着地・交換**: 支持脚交換、ポンプが自動転流して再武装、C2対称で次の構えへ。

## 4. 実験結果（PyBullet, 1/2400s, 平地）

- **構えの安定性**: 延長腕構成で全試験パラメータ域（ロッカーオフセット
  0.02〜0.12、減衰0.02〜0.3、ブレーキ有無）において転倒ゼロ。
- **初歩行**: Q=0.15kg/sで2フリップ・+1.67m/22秒（のち転倒）。
- **保守型（転倒なし）**: R_toe=0.40・μ=2.0・Q=0.15で**90秒間転倒ゼロ・
  +0.43m・クランク+6.45rad**。ただし2歩後にポンプ規則由来の駐機状態あり。
- **高速型**: 前方移送規則＋フリーホイールラチェットで**+1.93m/17.8秒
  （0.11m/s＝Gen-4の2倍）**、ただし前方転倒あり。安定化は位相同期制御待ち。

## 5. 開発で確定した知見

1. **剛体ボールト型の一歩は幾何学的に不成立**: つま先支点→タンクの回転半径
   （約1.0m）が機体高を超え、50°で必ずタンクが接地する。振り子通過型が正解。
2. **吊りアセンブリは自己平衡する**: 水をいくら移しても機体重心の接地投影が
   ピン直上から動かず、線量が全量まで暴走する。対策は股の一方向コード
   （人形の紐）——「水銀の移動と手足のバランスがポイント」の後半の機構的意味。
3. **つま先弧半径のトレードオフ**: R>h_com(0.46)で前方転倒は根絶されるが
   推進も死ぬ（受け皿化）。R=0.40が転倒保護と推進の両立点。**踵の平底は
   不可侵**（逆転構成は後方雪崩−6mで即失格）。
4. **足の接地摩擦が歩幅を決める**: μ=0.9ではフリップ反動で立脚が後方スリップ
   し正味後退。μ=2.0（ゴム底）で正味前進に反転。
5. **クランク角の逆巻き禁止（フリーホイール）が位相を守る**: 導入で速度倍増。
6. **ポンプ方向の局所規則は駐機アトラクタを生む**: 「低→高」「前方へ」いずれも
   複数の安定駐機姿勢（後傾満水高・50/50均衡・前満水閉ループ）に嵌まる。
   歩行サイクル位相に同期した移送制御（クランク角連動ロータリーバルブの
   ソフトウェア版）が必要。
7. **書き戻し検品**: 宙返りは股まわり＝基部ごと回るため、基部ピッチを転倒判定に
   使ってはならない。足回り造形は正面視チェックも必須（横ズレ検出）。
8. **可視化**: 剛体タンクは変形させず、内部のWaterボックスの水位で水量を表現。

## 6. 制約・今後の課題

- 位相同期コントローラ（着地→整定→規定線量→凍結の1歩状態機械）による
  「速くて転ばない」の両立
- 駐機アトラクタからの自動復帰（弁開放排水の位相条件付き運用）
- エネルギー効率（現状19〜37J/90秒はGen-4比で揚水ヘッドが大きい）
- 坂道モード（下りの純受動段返り）・不整地・3D化
- 実寸部品：回転側搭載ポンプの給電（スリップリング/搭載電池）、
  フリーホイール、股コードの張力設計
