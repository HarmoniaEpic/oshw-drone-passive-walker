# 第1世代：クアッドロータ安定化受動歩行機（attitude-only 構成）

**対応ファイル**: `gen1_drone_walker_attitude_only.blend` / `walker_pybullet.py` /
`walk_traj_attitude_only.json` / `drone_walker_attitude_only.mp4`

---

## 1. 概要

受動歩行機（膝付き4脚・McGeer型）の股関節台座にクアッドロータを一体化した初代構成。
「移動エネルギーは脚の振り子力学、安定化はドローンの飛行制御」という役割分担を
最初に実証した世代。段階的な補正削減試験により、ドローンの必須機能が
**姿勢制御と水平推力（エネルギー補給）のみ**であることを特定した。

## 2. 機体構成

| 要素 | 仕様 |
|---|---|
| トルソ | 股関節車軸＋矩形台座＋対角4アーム先端ロータ（低重心配置・台座上面は上半身搭載用に確保）、1.2 kg |
| 大腿 | 各 0.22 kg、長さ 0.40 m、股関節はフリーヒンジ（完全受動） |
| 下腿 | 各 0.20 kg、長さ 0.40 m、膝は反張ストッパ（+0.08 rad）付き |
| 足 | 半径 0.12 m の円弧足（脚長の15%）、下腿軸から前方 0.04 m オフセット |
| 総質量 | 2.24 kg（総重量 22.0 N） |

**設計の要点**
- 円弧足の前方オフセットは床反力線を膝軸の前に通し、立脚中の膝を
  ストッパへ押し付け続ける座屈防止機構（実機文献と同じ手法）
- 外側大腿ペアの連結は股関節軸上を跨ぐヨークアーチとし、内脚可動域との干渉を回避

## 3. 制御アーキテクチャ（イベント駆動・1200 Hz）

| 系 | 実装 |
|---|---|
| センサー | 足別接地法線力、関節角・角速度 |
| ヒールストライク判定 | 遊脚接地力 > 8 N かつ 遊脚股関節角 < −0.08 rad かつ 遊脚時間 > 0.2 s |
| 膝ラッチ | 立脚＝強保持（300 N·m 上限で 0.08 rad へ）。遊脚＝トーオフ折りパルス（0.18 s、上限 1.5 N·m）→ 自由屈曲 → 股関節角 −0.10 rad 通過で再伸展 |
| ドローンFC | 姿勢PD（kp 80 / kd 10）＋速度追従（kv 5、目標 0.38 m/s）。**高度支持なし（KZ=0）** |

## 4. 実験結果（最終構成）

- **10歩連続・8秒・転倒なし**、平均 0.32 m/s
- 歩行周期 0.72 / 0.91 s の交互（周期2リミットサイクル）
- 平均推進力 0.31 N、推進の機械仕事 0.1 W 級
- 補正削減スイープの結論：高度支持は 400 N/m → 0 まで完全撤廃可能。
  速度補給ゲイン KV ≥ 4–5 が下限（KV=3 では高度支持の量に関係なく2歩で転倒）
  ＝ 平地では推力がヒールストライク損失を補填するエネルギー源であることの定量的裏付け

**エネルギー比較**：同機体を単体飛行させる場合の誘導パワー約186 W（電気入力 ~265 W）に対し、
歩行アシストの機械仕事は3〜4桁小さい。実機換算でも10〜50倍の節約見積り。

## 5. 開発過程で確定した知見

1. 遊脚が支持脚と平行になる瞬間の接地（toe scuffing）は直脚系の本質的欠陥で、
   膝機構＋トーオフ折りパルスがなければ2歩目が出ない
2. 一定剛性の膝バネでは立脚座屈防止と遊脚屈曲が両立不可能 → 状態依存ラッチが必須
3. 発進は死点（静的平衡）からではなく、関節角速度込みの歩行中間状態から与える
4. 定速クランプは振り子交換を殺す — 速度制御は平均への緩い補給に留める

## 6. 制約・注意

- 姿勢安定は能動制御（FC帯域）に依存。制御停止＝即転倒（発散時定数 ~0.27 s）
- .blend はキネマティック再生の可視化リグ。物理の原本は `walker_pybullet.py`
  （KZ / KV を CLI 引数で変更可能：`python walker_pybullet.py out.json <KZ> <KV>`）
- PyBullet モデルは脚ペアを面内1本に縮約した2D拘束相当（横方向は代理拘束）
