# ドローン安定化受動歩行機 — コンセプトノート

**日付**: 2026-07-27
**状態**: シミュレーション実証済み（PyBullet 1200 Hz / Blender 可視化）

---

## 1. 概要

受動歩行機（passive dynamic walker）の上部にマルチロータを一体化し、
**移動エネルギーは脚の振り子力学、安定化はドローンの飛行制御**という分担で
平地を歩行させる機体コンセプト。シミュレーションで持続歩行（10歩・8秒・転倒なし）を実証した。

## 2. 着想の核

### 2.1 振り子効率のドローンへの導入

ローター揚力は重力と常時対抗し続けるため誘導パワーを払い続ける。
一方、歩行は運動エネルギーと位置エネルギーを振り子交換で往復させ、
支払いはヒールストライクの衝突損失のみ。
飛行・歩行ハイブリッド機の歩行側を**完全受動脚**とすることで、
歩行モードのアクチュエータコストをほぼゼロにできる。

### 2.2 倒立振り子の「正立振り子化」（本コンセプトの肝）

- 立脚は倒立振り子であり、固有値 +√(g/ℓ) の発散モードを持つ
  （ℓ≈0.72 m → 発散時定数 ≈ 0.27 s）
- 重心**上方**に搭載したドローンが安定化レンチ（姿勢トルク＋復元力）を
  供給すると、発散モードは振動モードに転換され、系は「上の支点から
  吊られた正立振り子」と等価な安定構造になる
- ヒト歩行の **Virtual Pivot Point**（Maus et al. 2010）— 床反力線を
  重心上方の一点に通して体幹を正立振り子として安定化する機構 — の
  **物理的実装**と位置づけられる
- 発散時定数 0.27 s ≒ 必要制御帯域は数 Hz。クアッドFCの姿勢ループ
  （数百 Hz）で余裕をもって抑えられる。**不安定の抑制は力ではなく
  帯域の勝負であり、帯域はエネルギーをほぼ消費しない**

## 3. 実証構成

### 機体（Blender で設計、質量・寸法を PyBullet に移植）

| 要素 | 仕様 |
|---|---|
| トルソ | 股関節軸上の矩形台座＋対角4アーム先端ローター（上半身搭載スペース確保）、1.2 kg |
| 脚 | 大腿0.22 kg＋下腿0.20 kg ×2、脚長0.8 m（大腿0.4／下腿0.4） |
| 膝 | 反張ストッパ（+0.08 rad）付きヒンジ。McGeer型 |
| 足 | 半径0.12 mの円弧足（脚長の15%、Collins機準拠）、前方4 cmオフセット（膝座屈防止） |
| 股関節 | **完全受動**（フリーヒンジ） |

### 制御（イベント駆動、1200 Hz）

| 系 | 実装 |
|---|---|
| センサー | 足別接地法線力（ロードセル相当）、関節角・角速度（エンコーダ相当） |
| 歩行状態機械 | 遊脚接地力 > 8 N かつ 股関節角 < −0.08 rad → ヒールストライク→立脚/遊脚交代 |
| 膝ラッチ | 立脚=強保持（McGeer吸盤ラッチ相当）／遊脚=トーオフ折りパルス（0.18 s・上限1.5 N·m）→自由屈曲→股関節角ゲートで再伸展 |
| ドローンFC | 姿勢PD（維持）＋水平推力（平均速度の緩い補給）。**高度支持はゼロまで削減可能** |

### 結果（最終構成：姿勢＋水平推力のみ）

- 10歩連続・8秒・転倒なし、平均速度 0.32 m/s
- 歩行周期 0.72／0.91 s の交互（周期2リミットサイクル — 受動歩行の既知現象）
- 遊脚膝屈曲 最大 −1.0 rad、腰高さ変動 0.824–0.837 m（自然なボールト）
- 平均推進力 **0.31 N**、推進の機械仕事 **0.1 W級**

## 4. エネルギー比較（総質量 2.24 kg・0.32 m/s）

| モード | パワー | 輸送コスト COT |
|---|---|---|
| 単体飛行（ホバー、運動量理論・4×r10cmロータ） | 誘導186 W／電気入力 約265 W (FoM 0.7) | 26.5 |
| 歩行アシスト（機械仕事） | 0.1 W級 | 0.001–0.01 |
| 歩行アシスト（実機見積り：制御権限用ベース推力・プッシャープロップ・アビオニクス込み） | 5–30 W | — |

**実機換算でも1〜2桁、機械仕事ベースで3〜4桁の節約。**
飛行10分の機体が歩行モードで2〜8時間動ける計算になる。
（参考：Collins機は4.8 kgで重力パワー1.3 W — 本結果と整合）

## 5. 削減試験で得た定量的知見

| 高度支持 KZ | 速度補給 KV | 結果 |
|---|---|---|
| 120→10 | 4–6 | 完走 |
| **0** | **5–6** | **完走（姿勢＋推力のみ）** |
| 任意 | ≤3 | 2歩で転倒 |

- 高度支持は**完全撤廃可能** — ボールトの上下動は脚が自前で生成
- 譲れないのは**エネルギー補給**（KV ≥ 4–5）。平地では推力が斜面の
  位置エネルギーを代替する、という当初仮説の定量的裏付け

## 6. 開発過程で確定した設計要件（文献照合済み）

1. **円弧足は脚長の~15%半径、前方オフセット付き** — オフセットは床反力線を
   膝の前に通し、立脚膝をストッパに押し付け続ける座屈防止機構
2. **膝ラッチは状態依存が必須** — 一定剛性のバネでは立脚座屈防止と遊脚屈曲が
   両立不可能（McGeerの吸盤、Wisseのラッチの理由）
3. **トーオフの膝折りインパルスが第2歩目以降の生命線** — 遊脚が平行位置で
   接地する「toe scuffing」は直脚系の本質的欠陥で、膝＋折りパルスで解消
4. **発進は死点からではなく歩行中間状態から**（関節角速度込み）。
   実機文献でも「不適切な初期条件が失敗の主因」（成功率80%）
5. 定速クランプは振り子交換を殺す — 速度制御は「平均の緩い補給」に留める

## 7. 今後の課題

- 外乱応答試験（押し・段差）— 「正立振り子化」の安定余裕の定量化
- 速度指令追従（ドローン推力によるギア変更）
- 3D化（横方向・ヨー）: 現構成の4脚フレームは2D拘束。Collins機の
  横揺れ結合・カウンタースイングアームが参考になる
- 台座上への上半身搭載（マニピュレータ等）と質量変動への適応
- 実機化：膝ラッチ機構（電磁ラッチ or 小型サーボ）、水平推力用
  プッシャープロップ、姿勢はFC標準機能で足りる
