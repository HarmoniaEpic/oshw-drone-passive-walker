# 第6世代：二連クランク式歩行機（ギア同期平行リンク脚）

**対応ファイル**: `gen6_walker.blend`（Gen-5モデルからの改造）/ `walker_gen6.py`
（PyBulletシミュレータ）/ `gen6_walker_walk.mp4`（90秒完走歩行の動画）。

---

## 1. 概要

Gen-5の失敗解析はすべて一点に収束した——**脚の姿勢（向き）が拘束されて
いない**。着地捕捉の失敗、ピン半径RCを伸ばしてもクリアランスが増えない相殺、
股コード・股ブレーキ・フリップロックという対症療法群は、いずれも自由振り子の
脚を間接的に躾けようとした症状だった。

Gen-6は各脚を**前後2本の同半径・同位相クランク**で吊り、**各脚内側面の
3枚ギア列**（ピン同心ギア2枚＋アイドラ、1:1同方向）で平行四辺形の位相を
全域拘束する。脚はカプラとして**並進のみ**：足は常にフラットに着地・離地し、
歩幅は2·RCで決定論的、脚質量は対で相殺してクランク釣り合いから消える。

歩行様式は転換する。機体は直立を保ち、**段返り（宙返り）はタンクを載せた
クランクだけが担う**——体ごと返るGen-5から、水車のように回るGen-6へ。

## 2. 機体構成（Gen-5からの差分）

| 要素 | 仕様 |
|---|---|
| 前方クランク | Gen-5クランク一式（タンク・中空腕・ハブポンプ/弁）をx=+0.10へ移設 |
| 後方クランク | 屈曲1回のZ形：左右ピン線（180°対向・前と同位相）＋中央の軸直角ジョグ（長さ2·RC）。中心ハブなし。**脚の貫通軸受けのみで保持（浮動）**、回転はギアが拘束 |
| ギア列 | 各脚内側面（y=∓0.105）：ピン同心ギアr=0.06×2＋脚軸支アイドラr=0.04。中心距離0.10=軸間D/2。外歯3枚=同方向1:1（2枚だと交差四辺形を強制するので不可） |
| 脚板 | 上部をz=0.45から上端へテーパー拡幅（上端±0.14m）、前後軸受けボス追加 |
| 足 | ロッカー全面更新：つま先弧**R=0.55**（h_com=0.52超）、接線位置X_TOE=+0.10、**踵平底を−0.18まで後方延長**（着地リバウンド受け） |
| 撤去機構 | 股コード・股ブレーキ・フリップロック（脚姿勢拘束により原理的に不要） |
| 総質量 | 3.86kg（Gen-5比+0.71kg：ギア6枚・後方クランク・ボス類、軽量化ギア想定） |

軸間D=0.20m。干渉はy方向の層別配置（中央ジョグ|y|<0.024／クランク腕±0.05-0.07
／ギア±0.10-0.11／脚板±0.115-0.165／タンク±0.44）で回避——全回転36姿勢×
170部品対のBVH検証で干渉ゼロ。

## 3. 動作原理

1. **構え**: 脚質量が対で相殺するため、自由平衡は「満水タンク鉛直吊り」
   （th=−atan2(R_T,DZ_T)=−0.885rad）。フリーホイール（遊び0.15rad＋掛止減衰）に
   凭れて−0.6付近に駐まり、水は軸鉛直線の後方に垂れる。**後退禁止が次の一歩の
   転倒方向を前方に確定する**（Gen-5の首オフセットと同じ役割を機構が担う）。
2. **揚水（CHARGE）**: 後方低タンクから前方高タンクへ移送。クランクが動き出した
   瞬間（|ω|>0.5）に弁凍結——**線量はフリップ開始で自動的に上限が掛かる**。
3. **反転（FLIP）**: クランクだけが半回転。機体・脚は直立のまま（ピッチ±3°）、
   基部が2·RC·cosθ≈0.13m前進し、遊脚が並進で前方へ着地。
4. **整定（SETTLE）**: 着地リバウンドをフリーホイールの遊び＋掛止減衰と延長踵が
   吸収。静穏化を検知して次のCHARGEへ。C2対称で構えが再現される。

## 4. 実験結果（PyBullet, 1/2400s, 平地, 位相同期制御）

- **全試験Q域（0.15〜0.50kg/s）で90秒間転倒ゼロ**。
- 最良点 Q=0.30：**+2.42m・18歩・クランク+53.7rad（17回転）・最大ピッチ6.8°・
  0.027m/s**。
- **1歩=0.134m＝運動学的歩幅2·RCがそのまま出る**（Gen-5のスリップ損失ゼロ）。
- 仮想ギア偏差（バックラッシュ相当）は全域≤2.4°。
- つま先弧R_TOE（0.40/0.55/0.65）は歩行性能に無影響＝**推進がつま先ロールから
  完全に分離**。ただしQ=0.30の過渡ではR=0.40が62秒で転倒、R=0.55は完走
  ——大円弧は無償の転倒保護として機能する。

## 5. 開発で確定した知見

1. **仮想ギアを股関節トルクで実装してはならない**: 反作用が前クランク軸に集中し
   正帰還で発散（0.1秒でω=9rad/s）。実機構ではピン力対のクランクトルクがギア
   経由で相殺し反力は基部へ抜ける——シミュレーションでは脚⇔基部間の外部偶力
   として実装するのが正しい。
2. **平行リンク化で構えの平衡が移動する**: 脚の重力モーメントが左右対で相殺し、
   平衡は純粋に水の吊り角で決まる。Gen-5の構え角をそのまま使うと転倒する。
3. **フリーホイールが転倒方向決定器になる**: 鉛直吊り平衡は水を持ち上げると
   方向不定になるが、後退禁止が前方を選ぶ。
4. **着地リバウンドの吸収系が必須**: 過回転の跳ね返り→硬い掛止→基部後傾→
   踵後端越えの後方転倒が唯一の転倒モードだった。ラチェット遊び0.15＋掛止減衰
   ＋踵後方延長で根絶（踵は平底のまま延長：Gen-5知見「踵平底不可侵」と両立）。
5. **リンク（サイドロッド）のみの平行拘束は死点で破綻し得る**: クランク水平で
   左右同時に一直線（180°対向のためクォータリング不可）。ギア列・チェーンは
   角度そのものを拘束するため死点が存在しない。3枚（同方向）が必須。
6. **線量制御は位相機械に統合される**: CHARGE→FLIP遷移（クランク始動検知）が
   「ちょうど返る分だけ」の移送を自動実現。無制御の前方移送則は全水量集中→
   過大フリップ→転倒（Gen-5知見の駐機アトラクタの終着形）。
7. **後方クランクの中央軸受け支持は幾何学的に不可**: ピン掃引（|y|=0.01〜0.19）と
   ジョグ掃引（|y|<0.024）が回転面を埋め、基部からの支持ブラケットの通り道が
   ない。浮動＋ギア拘束が正解。

## 6. 制約・今後の課題

- 歩行速度0.027m/s：歩周期約5秒はSETTLE整定（0.8s）とCHARGE移送時間が支配的。
  整定条件の短縮・Q最適化・RC=0.09（歩幅+29%）の検証
- エネルギー約5.4J/歩（Q=0.30・90秒で97J）の低減
- 実機ギアの軽量化（ソリッド金属では6枚で2kg超——ウェブ抜き・樹脂化の設計）
- 円弧軌道接地に固有の着地スカッフ（ロッカーで緩和済みだが残存）
- クランク反動トルクが機体を通る経路（Gen-4系）の定量化
- 防衛公開：ギア同期平行クランク脚案内は歩行玩具・機関車連結棒に連なる古典
  機構の組み合わせであり、先行技術欄への追記が必要

| 世代 | 姿勢安定 | 推進エネルギー | 特徴 |
|---|---|---|---|
| 第1（クアッド） | 能動（FC姿勢PD） | ファン水平推力 | 帯域で安定化 |
| 第2（球形気嚢） | 受動（浮力） | ファン水平推力 | 消費電力ゼロ化 |
| 第3（飛行船型） | 受動（浮力＋尾翼） | ファン水平推力 | 方向性・風見安定 |
| 第4（段返り式） | 質量幾何のみ | 水移送＋蓄圧ベローズ | 水が質量・重錘・作動流体を兼任 |
| 第5（段返り水車式） | 質量幾何＋構え | 水移送のみ | タンクがクランクに乗り体ごと返る |
| **第6（二連クランク式）** | **質量幾何＋脚姿勢の機構拘束** | **水移送のみ** | ギア同期平行リンクで足が常にフラット、機体直立・歩幅決定論、全Q域転倒ゼロ |
