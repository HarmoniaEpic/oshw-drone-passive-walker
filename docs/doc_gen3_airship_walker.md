# 第3世代：飛行船型歩行機（回転楕円体気嚢＋十字尾翼）

**対応ファイル**: `gen3_airship_walker_face.blend` / `walker_airship.py` /
`walk_traj_airship.json` / `airship_walker_face.mp4`（旧版 v1/v2 動画あり）

---

## 1. 概要

第2世代の球形気嚢を**飛行船型（回転楕円体）気嚢＋船尾十字尾翼**に発展させた
現行世代。「足の生えた飛ばない飛行船」。浮力による受動姿勢安定という
第2世代の原理はそのままに、細長気嚢による前後方向性と、尾翼による
回転減衰・風見安定性を獲得した。

## 2. 機体構成（第2世代からの変更点）

| 要素 | 仕様 |
|---|---|
| 気嚢 | 回転楕円体（全長 2.2 m × 直径 0.9 m、フィネス比 2.4）、長軸を進行方向に一致 |
| 浮心 | 気嚢は前後対称のため幾何中心＝浮心。**浮心を機体重心の鉛直上方に配置**し静的トリムをゼロに（尾翼質量の後方偏りは機首バラストで相殺する前提で、質量集中点を浮心に一致させて模擬） |
| 尾翼 | 船尾に十字配置4枚（水平安定板2＋垂直安定板2）。船尾断面半径 0.27 m の外側へ翼幅 0.34 m を張り出し |
| マスト | **門型（ポータル）構造**：垂直支柱2本を外脚ヨーク可動域（y=±0.22）の外側 y=±0.30 に配置、掃引頂部の上方 z=1.04 にクロスバー、斜材で頂点集約後に単管で気嚢腹部へ。第2世代の干渉問題を解消し、三角トラス化で剛性も向上 |
| 気嚢系質量 | 0.30 kg（外皮＋尾翼＋マスト） |
| 総質量 | 2.54 kg（総重量 24.9 N） |
| 外装 | 気嚢・尾翼は白。機首側面左右に円形マーキング1対（装飾） |

## 3. 物理モデルの追加要素

| 項目 | 実装 |
|---|---|
| 気嚢回転慣性 | 細長胴体のピッチ／ヨー慣性を気嚢リンクに設定（0.02 / 0.07 / 0.07 kg·m²） |
| 尾翼減衰 | ピッチ・ヨー角速度に比例する減衰トルク（各 0.5 N·m·s/rad）。気嚢振り子スロッシュを抑制 |
| 胴体抗力 | 並進抗力係数を球形時の 0.35 → 0.80 N·s/m に増加 |

## 4. 実験結果

| 浮力 | 結果 |
|---|---|
| 10 N（40%W） | 転倒 — 気嚢の質量・慣性増で適正窓下限が第2世代（37%）より上昇 |
| **13 N（52%W）** | **9歩完走**、ピッチ±3.4°、ファン平均 0.53 N |
| 16 N（64%W） | 9歩完走、ピッチ±2.9° |

推奨適正値は引き続き**浮力 ≈ 52%W**。歩容・エネルギー特性は第2世代とほぼ同等で、
形状変更のコスト（慣性増による窓下限上昇）と利得（尾翼減衰・方向性）が拮抗する。

## 5. 尾翼の位置づけ

歩行速度 0.3 m/s 程度の屋内条件では、尾翼は主として**回転減衰器**として働く。
本領は屋外・3D化した際の**風見安定**（機首を相対風に向ける復元）であり、
第2世代の球形気嚢では原理的に得られない方向安定性を仕込んだ装備である。

## 6. 制約・今後の課題

- 実寸の気嚢体積：浮力 13 N には約 1.3 m³ が必要。モデルの外形（約 0.93 m³ 相当）は
  やや理想化されており、実機ではフィネス比を保ったまま全長を伸ばすか機体軽量化が必要
- 横方向・ヨーの動力学は4脚フレーム相当の代理拘束で2D化されている。
  3D化時は尾翼・アジマスファンのヨー制御が本格的に効いてくる
- 外乱応答（突風・押し外乱）試験は未実施
- .blend は可視化リグ。物理の原本は `walker_airship.py`
  （`python walker_airship.py out.json <浮力N> [KV]`）

## 7. 世代系譜まとめ

| 世代 | 姿勢安定 | 推進 | 特徴 |
|---|---|---|---|
| 第1（クアッド） | 能動（FC姿勢PD） | ロータ推力 | 帯域で安定化。制御停止＝転倒 |
| 第2（球形気嚢） | **受動（浮力）** | アジマスファン×2 | 安定化の消費電力ゼロ化 |
