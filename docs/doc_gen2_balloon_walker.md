# 第2世代：バルーン受動安定歩行機（球形気嚢＋アジマスファン）

**対応ファイル**: `gen2_balloon_walker.blend` / `walker_balloon.py` /
`walk_traj_balloon.json` / `balloon_walker_walk.mp4`

---

## 1. 概要

第1世代で「ドローンの必須機能は姿勢制御と水平推力のみ」と判明したことを受け、
**姿勢制御を能動（FC）から受動（浮力）へ置き換えた**世代。
マスト頂部のヘリウム気嚢が重心上方に浮力を供給し、機体が傾くと自動的に
復元トルクが生じる（船舶のメタセンタ安定と同原理）。倒立振り子の発散モードが
「上の支点から吊られた正立振り子」の振動モードに転換される。

推進は台座両脇のアジマス式ダクテッドファン1対に縮約。掘削船の動的位置保持や
飛行船の推力偏向と同じ「支持は別系統・推進器は位置と向きの調整のみ」の思想。

## 2. 機体構成（第1世代からの変更点）

| 要素 | 仕様 |
|---|---|
| 気嚢 | 球形、マスト頂部（股関節上方 1.55 m）に搭載。浮力 B は試験パラメータ |
| 気嚢系質量 | 0.25 kg（外皮＋マスト、取付点に集中） |
| 推進 | アジマス式ダクテッドファン×2（車軸端アウトリガー y=±0.36、水平推力のみ） |
| ロータ | クアッド4基 → 撤去 |
| 総質量 | 2.49 kg（総重量 24.4 N） |
| 制御 | **能動姿勢制御ゼロ**。ファンは平均速度の緩い補給（kv 5）のみ。ヨー減衰・横方向は4脚フレーム代理拘束 |

脚系（膝ラッチ・円弧足・イベント駆動歩行状態機械）は第1世代と同一。

## 3. 適正重量試験（本世代の主題）

浮力 B を総重量比 0〜102% で掃引した結果：

| 浮力比 | 挙動 | 決定要因 |
|---|---|---|
| 0〜33% | 転倒（ピッチ発散 7〜35°） | 復元トルク B·h が倒立振り子の発散に不足 |
| **37〜94%** | **9歩完走** | 適正窓。浮力増でピッチ振れ 3.5°→1.8°、ファン推力 0.57→0.23 N と単調改善 |
| 98〜99% | 転倒しないが1歩のみ | 接地力喪失で歩容が消滅（滑走状態） |
| ≥102% | 浮上 | 浮力＞重量 |

**推奨適正値：B = 13 N（53%W）** — ピッチ±3.0°、ファン平均 0.52 N、
脚に体重の47%が残り摩擦余裕（外乱耐性）を確保。

実寸換算：ヘリウムの正味揚力 ≈ 1.02 kg/m³ より、B=13 N には約 1.3 m³
（球なら直径約 1.4 m）の気嚢が必要。機高 0.85 m に対して大きく、
実機化では軽量化または細長形状の検討課題（→第3世代）。

## 4. 本世代で得た知見

1. 姿勢安定はエネルギーではなく**復元トルクの幾何**で賄える。消費電力ゼロ、
   制御系停止時も姿勢が保たれるフェイルセーフ性を獲得
2. 「浮きすぎ」の失敗は浮上（102%〜）より先に**歩容の崩壊**（98%〜）として現れる
3. 残る消費はファンの水平推力（平均 0.3〜0.6 N、機械仕事 0.2 W 級）のみ

## 5. 制約・既知の問題

- **マストとヨークアーチの幾何干渉**：センターマストが外脚連結ヨークの掃引域を
  通る設計欠陥がこの世代には残っている（第3世代の門型マストで解消）
- 球形気嚢は回転減衰を持たず、振り子スロッシュの減衰は空気抵抗頼み
- .blend は可視化リグ。物理の原本は `walker_balloon.py`
  （`python walker_balloon.py out.json <浮力N> [KV]`）
