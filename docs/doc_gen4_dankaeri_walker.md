## 1. 概要

からくり人形「段返り童子」——体内の液体（水銀）の移動で重心を移し階段を
宙返りで降りる——の**平地歩行版**。第1〜3世代が追求した「姿勢安定装置」系列
（能動FC→受動浮力）の帰結として、本世代は**装置そのものを消滅**させた：
質量の大半を水として足元に集中させ（h_com=0.288m ＜ つま先弧R=0.30m）、
機体は質量配置の幾何だけで転倒しない。

水が全役職を演じる：**質量**（安定）、**重錘**（駆動エネルギー）、
**移送体**（重心シフト＝推進）、**作動流体**（ベローズ駆動）。外部入力は
マイクロポンプの電力のみで、下り坂では原理的にゼロにできる。

## 2. 機体構成

| 要素 | 仕様 |

| 脚 | 膝なしトラスカラム2本（同一部品、長さ0.695m）。上端をクランクで結合 |
| クランク | 半径RC=0.07m・軸高0.84m。1反転＝半回転＝1歩。180°デテント円盤付き |
| 股関節 | 貫通ピン＋**連続回転ゴンドラ軸受**（フェリスホイールの客車と同じ） |
| 足 | **半かまぼこ**：踵側平底0.20m＋足中心を接線とするつま先弧R=0.30m。接地幾何の機械式ダイオード（後方転がり不可・前方のみ閾値つきで転がる） |
| 足板 | 二重フレーム＋4隅コイルバネ、ストローク50mm。着地衝撃吸収兼ラック駆動源 |

## 3. 動作原理 — 重錘式振り子時計との対応

| 時計 | 本機 |
|---|---|
| 重錘（分銅） | ポンプが充圧する駆動ベローズ |
| 香箱・輪列 | ベローズ→ラック→ピニオン→クランク |
| ガンギ車＋アンクル | フリーホイール＋180°デテント＋解放ラッチ |
| 振り子の等時性 | 水移送の時定数（ホース径・ポンプ流量が刻む） |
| 文字盤 | 前進距離 |

**1歩のサイクル**：ラッチ（＝ロータリーバルブ閉）中にポンプがベローズを充圧
→ 並行して水が前足へ転流（重心前進、平底ダイオードが前進分だけ保存）
→ **段返り条件（水移りきり ∧ 充圧完了）で解放**
→ ベローズがラックを押しクランクがスナップ半回転（後脚＝軽い側が前へ）
→ 遊脚が踵平底で着地しキャッチ → デテント着座・再ラッチ → 次周期。

## 4. 実験結果（PyBullet, 1/2400s）

- **転ばない性**：h_com<R＋平底ダイオードにより、調律版は全40秒試験で転倒ゼロ
- **半かまぼこの効果**：対称ロッカーで毎回発生した後方整定ロール・後方雪崩が
  根絶され、水装填だけで**初の系統的前進**（+0.10〜0.12m）が出現
- **間欠スナップ回転**：クランクは「溜め→スナップ→デテント着座」の階段波形で
  0→π→2π→…→**8πまで完全量子化**（等速回転にはならない——設計意図どおり）
- **連続歩行**：**15kPa×0.15L調律で6歩/40秒・前進+2.17m・転倒ゼロ**
  （平均5.4cm/s）。世界座標ピッチは全区間±0.4°以内。線量を増すと
  デテント通過後の捕捉に失敗して転倒（脱進機の線量調律問題）
- **開発時の重大な計測教訓**：クランク駆動トルクを関節に与えると反作用が
  自由浮遊の軸体に落ち、軸体が逆回転してクランク相対角が「偽の反転」を
  量産した（機体は世界座標で宙返りしていた）。反作用を実機の荷重経路
  （ラック→立脚足）へ明示的に配線し直して初めて上記の正しい歩行が得られた。
  併せて、立脚股ブレーキは**ラッチ保持中のみ**係合（反転中はゴンドラ解放）が
  段返りの正しい順序であることも確定した

## 5. 開発で確定した知見

1. **板間加圧水嚢は設計矛盾**：荷重経路内の水嚢は立脚から水を追い出す＝
   アンカー質量集中と真逆。水嚢はバネ上カーゴ（圧力中立）が正解
2. **移送は水柱イナータンス（ρL/A）支配**：クランク上を越える長ホースは不成立。
   低位短ホース（0.4〜0.5m・太径）が必須。長ホース化はポンプ5〜10kPa増圧で可能
3. **対称ロッカーは双方向に転がる**ため後方雪崩・その場足踏みのアトラクタを作る。
   半かまぼこ（平底＋つま先弧）が制御パッチ3件を幾何1つで置換した
4. **準静的スロッシュがラックに流せる力は水の重量変化分（~6N）のみ**（0.1J/移送）。
   反転の壁（~2J）はベローズのような蓄圧アクチュエータでのみ越えられる
5. 脚は左右同一部品・股は連続回転軸受・立脚股は荷重連動ブレーキ——
   段返り人形の「宙返り中は剛体」の機械翻訳
6. （実装教訓）速度クランプ型の数値ラチェットは接触ジッタを回転に整流する
   （ファインマンのラチェット）。片側位置拘束バネ型が正しい

## 6. 制約・今後の課題

- ベローズ線量の調律（0.28〜0.4Lの間）・再ラッチ時の余剰圧ベント・着地減衰に
  よる正味歩幅の最適化（現状は歩間の後方スライドで正味前進が目減り）
- 下り坂の純受動モード（ポンプゼロ）の成立確認と、斜面での線量自動減
- 3D化（横方向・旋回）、不整地試験（歩行書き戻し・動画化・OSHW追加・図面は完了）
- 実寸部品選定：ポンプ12〜16kPa・0.15L/s級、ベローズ受圧0.008m²、
  フリーホイール・ワンウェイクラッチの市販品調査
